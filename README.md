# 🏏 ZombAi-Ganador

**ZombAi-Ganador** is an advanced **AI-inspired cricket match prediction simulator** that analyzes match factors, historical performance, venue conditions, and team statistics to predict match outcomes.

Designed with a **luxury sports analytics interface**, the platform combines **data visualization, stadium intelligence, and predictive modeling** to simulate real match outcomes.

# 🚀 Features

## 🎛 Match Configuration

Configure a full international match scenario before running predictions.

Options include:

- **Match Format Selector**
  - ODI
  - T20I
  - Test

- **Team Finalists**
  - Choose from **10 international teams**
  - Includes **flag emojis for visual identification**

- **Tournament Stage Selector**
  - Finals
  - Semi-Finals
  - Group Stage
  - Knockouts

- **Stadium Selector**
  - **21 international venues**
    - 8 Indian stadiums
    - 13 global stadiums
  - Includes **real capacity and pitch conditions**

---

# 🧠 Predictive Engine

The core prediction engine analyzes multiple data layers to estimate match outcomes.

### Prediction Metrics

- **Win Probability (%)**
- **Loss Probability (%)**
- **Draw Probability (Test matches only)**

### Data Intelligence

The model uses:

- **40 years of weighted historical match data**
- **Format-specific performance**
- **Finals record history**
- **Team head-to-head outcomes**

Animated **probability bars** display predictions using **physics-style easing animations**.

---

# 🌦 Match Factors Panel

The engine dynamically loads **stadium-specific environmental conditions** to influence predictions.

Displayed factors include:

- Pitch Type
- Temperature
- Humidity
- Wind Speed
- Venue
- Chasing Win %

All values are **automatically populated based on the selected stadium**.

---

# ⚔️ Chasing Analysis

The platform performs a **bat-first vs chase analysis** including:

- Bat First Win %
- Chase Win %
- Individual team chase probability

This helps determine which team benefits more from **toss outcomes and pitch behaviour**.

# 📊 Interactive Analytics Charts

The application includes **four advanced chart dashboards** with tabbed navigation.

---

## 1️⃣ Head-to-Head Analysis

Charts included:

- **Doughnut Chart**
  - 40-year head-to-head wins

- **Bar Chart**
  - Performance by batting position

- **Line Chart**
  - Decade-by-decade performance trend

---

## 2️⃣ Recent Form

A **Step Chart** visualizing recent performance:

- Win/Loss trends
- Momentum analysis
- Current team form trajectory

---

## 3️⃣ Batting Depth

A **Radar Chart** comparing both teams across **six performance axes**, such as:

- Top order
- Middle order
- Finishers
- Strike rate
- Consistency
- Depth

---

## 4️⃣ Pitch Analysis

Pitch and weather influence visualized through:

- **Polar Area Chart**
  - Pitch type dominance

- **Bar Chart**
  - Weather factor impact
